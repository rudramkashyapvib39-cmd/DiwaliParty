# 🪔 Diwali Filmy Wheel

A festive, mobile-first Bollywood dumb-charades party game for Diwali night.

Spin the golden wheel, act the film, shout the title — complete with diyas, fireworks and firecracker energy.

## Features
- Fully Diwali-themed UI (night sky, gold & saffron, diyas, fireworks)
- Designed for one phone in a room full of friends
- 2 teams / 4 teams / individual modes
- Twist modes, steal rounds, custom movies
- Works offline once loaded

## Quick start
Just open `index.html` in any modern mobile browser.

## Deploy (GitHub Pages)
After pushing to GitHub, go to **Settings → Pages → Source: Deploy from a branch → main / root**.

Your site will be live at:
`https://<your-username>.github.io/DiwaliParty/`
